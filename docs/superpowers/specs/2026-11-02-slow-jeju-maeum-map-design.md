# 느린 제주 마음지도 — 설계 초안

제주 웰니스 여행 AI 에이전트 웹앱 (Vite + React + Three.js, Supabase, Vercel). 제주 콘텐츠·문화 IP 주제 과제용.

## 의도
오늘의 기분을 고르면, 그 기분에 맞는 느린 하루 코스를 3D 제주섬 위에서 짜 주는 여행 추천 앱. 따뜻하고 차분한 분위기.

## 목표
- 마음 체크인(기분 선택) → 맞춤 코스
- 웰니스 레이어: 장소마다 분위기(고요함·자연·활력·위로 등)를 색으로 표시
- 느린 일정: 이동시간·걷는 거리 상한, 쉬는 시간 자동 삽입, 시간대 문구("커피 마시기 좋은 시간", "쉬어가는 시간", "명상하기 좋은 시간", "사색에 잠기기 좋은 시간")
- 3D 장면이 날씨·시간대에 따라 변함
- 장소별 짧은 리뷰, 코스 따라 기분 기록 (Supabase)
- 공공데이터 API 3개 이상을 에이전트 도구로 사용
- 마지막: GitHub, README, 발표 자료, Vercel 배포

## 웰니스 콘텐츠 (공공데이터 외, 사용자 선택 2026-11-02)
- 마이크로 쉼 카드: 장소 분위기별 "여기서 해 볼 5분" (호흡, 오감 알아차리기, 걷기 명상 등)
- 숨쉬기 좋은 날 / 사색하기 좋은 시간: Open-Meteo 대기질·자외선·구름양·일출일몰·월상으로 문구 생성
- 푸른 공간(바다·해변) / 초록 공간(오름·숲·올레길) 태그와 지도 색 구분. 효과를 단정하지 않고 "많은 사람이 편안함을 느끼는 곳" 같은 표현 사용
- 마음 문장: 장소·시간대에 맞는 짧은 감성 문장을 에이전트가 생성 (진단·조언 아님)
- 보류: 호흡 가이드 3D 애니메이션, 소리 지도 (여유가 있으면 추가)
- 웰니스 인증: 한국관광공사 웰니스관광정보(제주 6곳)에 해당하는 장소에 인증 표시

## 비목표 / 안티목표
- 진단·상담·치료 표현 금지. 화면에 항상 "의료·상담이 아닌 여행 추천" 표시.
- 위기 신호 문장에는 코스 대신 109(자살예방상담), 1577-0199(정신건강상담)를 먼저 안내. (번호는 발표 전 최신 확인)

## API
| 기능 | API | 키 |
|---|---|---|
| 관광지·사진·축제 | 한국관광공사 TourAPI 국문(KorService2) | 공공데이터포털 |
| 웰니스 분위기 | 한국관광공사 웰니스관광정보 (신청함, 엔드포인트 확인 필요) | 공공데이터포털 |
| 날씨·일출일몰 | Open-Meteo | 없음 |
| 맛집·카페 | 카카오 로컬 | 카카오 REST |
| 올레길 | OSM Overpass | 없음 |
| 이동시간·순서 | OSRM 공개 서버 | 없음 |
| 에이전트 | Anthropic API | 서버 키 |
| 저장 | Supabase | URL + anon key |

과제가 "공공데이터 API"로 인정하는 범위는 확인 필요(공공데이터포털 소속: TourAPI, 웰니스관광정보; 필요하면 에어코리아 추가).

## 단계 (단계마다 사용자 확인)
1. 골격 + 3D 섬 ✅
2. Supabase 연결 확인
3. 날씨 + 관광지 핀
4. 마음 체크인 + 맞춤 코스(에이전트)
5. 하루 동선(느린 일정) + 맛집·카페
6. 올레길, 웰니스 레이어, 리뷰·기분 기록
7. 3D 분위기 변화, 디자인 다듬기
8. GitHub, README, 발표 자료, Vercel 배포

## 제 판단으로 정한 것 (바꿀 수 있음)
- 기분 선택지 5~6개로 시작, 자유 입력은 나중.
- 위기 문구 감지는 키워드 방식으로 시작.
- 디자인은 밝고 부드러운 크림·연한 감귤·바다 안개 톤으로 다시 잡음(현재 임시 다크 테마).
- Supabase 정책은 수업용으로 anon 읽기·쓰기 허용(실서비스 전 인증 필요).
