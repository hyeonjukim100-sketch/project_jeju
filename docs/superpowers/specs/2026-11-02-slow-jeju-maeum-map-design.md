# 느린 제주 마음지도 — 설계 (2차 초안)

마음이 편해지는 제주 여행을 추천해 주는 AI 웹앱 (Vite + React + Three.js, Supabase, Vercel). 제주 콘텐츠·문화 IP 주제 과제용.
소개 문구는 "심리 지원"이 아니라 "마음이 편해지는 제주 여행 추천"으로 쓴다. (2026-11-02 사용자 결정)

## 의도
오늘의 기분을 슬라이더로 알려 주면, 그 기분에 맞는 느린 하루 코스를 3D 제주섬 위에서 짜 주는 여행 추천 앱. 따뜻하고 차분한 분위기. 모든 문장은 존댓말.

## 화면 구성 (사용자 결정)
1. **첫 화면(랜딩)**: 위에 다정한 인사말, 둥근 기분 슬라이더, 중앙에 3D 점토 캐릭터(해녀+현무암). 하단 웰니스 아이콘(명상·백색소음·감정일기)은 이번에는 뺀다.
2. **스크롤하면**: 날씨 → 3D 지도(관광지 핀·갤러리) + 하루 동선. 지도 위에 번호 핀과 선으로 동선을 그리고, 넓은 화면에서는 지도 옆 패널에 순서 목록, 모바일에서는 아래 패널.
3. **챗봇**: 화면 구석에 떠 있는 버튼(플로팅). 첫 화면과 스크롤 화면 어디서든 열린다. 캐릭터와는 별도의 대화창.
4. 위쪽 메뉴(하루 동선·AI 가이드·내 보관함)는 화면 안 위치로 이동하는 방식으로 정리 — **미정, 사용자 확인 필요**.

## 기분 슬라이더
- 한 줄: 지침 ↔ 활기. 5단계. 이모지와 단계 이름을 함께 보여 준다(색만으로 구분하지 않기 위해).
- 색: 붉은 산호색(지침) → 초록(활기) 그라데이션.
- 단계 이름(내 초안, 확인 필요): 😮‍💨 많이 지쳤어요 / 😔 조금 가라앉았어요 / 😐 그저 그래요 / 🙂 괜찮아요 / 😄 활기 넘쳐요
- 점수는 저장하지 않는다. 그때의 이모지만 여행 기록에 남긴다.
- 맞춤 코스는 슬라이더 값만으로 정한다(지침 → 조용·가까운 곳, 활기 → 더 걷는 곳 등). 마음의 결은 챗봇에서 자유롭게 말하면 에이전트가 다듬는다.
- 칩(불안·외로움 등)은 쓰지 않는다. 대신 일기 기록에 자유 입력 칸을 둔다(코스 추천에는 쓰지 않음).

## 디자인
- 계절 테마: 시스템 날짜로 자동 전환. 봄(3~5월) 연한 유채 노랑 + 물안개 연하늘 / 여름(6~8월) 에메랄드 바다 + 현무암 회색 / 가을(9~11월) 단풍 붉은빛 + 억새 톤 / 겨울(12~2월) 눈꽃 흰색 + 포근한 웜그레이. 지금(11월)은 가을. 구체 색값은 구현 때 시안으로 보여 드리고 확인받는다.
- 날씨·낮밤은 계절색 위에서 밝기만 바꾼다. 기존 어두운 남색 테마는 버린다.
- 형태: 모든 버튼·말풍선은 둥글고 부드럽게, 옅은 그림자.
- 인사말: "오늘 기분은 어떠세요?", "편안한 하루 보내고 계신가요?" 같은 존댓말.
- 캐릭터: 3D 점토 질감(해녀의 숨비소리·공동체, 현무암의 단단함). 모델은 사용자가 만들어 전달(형식 확인 필요: .glb 권장, 표정 변화 방식은 모델을 받은 뒤 결정).

## 안전
- 화면 아래에 항상 "의료·상담이 아닌 여행 추천" 안내.
- 위험 문구가 입력(챗봇·일기)에 있으면: 코스 대신 따뜻한 한두 문장과 연락처 카드를 먼저 보여 준다. 109(자살예방상담전화), 1577-0199(정신건강상담전화). 119는 넣지 않는다(사용자 결정). 일기 저장은 막지 않는다. 카드에 "코스 계속 보기"를 두어 사용자가 원하면 볼 수 있고, 아니면 숨는다. 진단하는 표현은 쓰지 않는다. 번호는 발표 전에 다시 확인.
- 챗봇에는 같은 규칙을 지시문으로도 넣어 두 겹으로 막는다.
- 위험 문구 목록 초안은 `src/lib/crisis.js`에서 관리(사용자 검토 후 확정).

## 계정과 기록
- Supabase 이메일 가입·로그인. 일기·기분 기록은 로그인한 본인만 읽고 쓰도록 행 단위 보안(RLS)으로 막는다.
- 가입/로그인 전에는 지도·날씨·관광지를 볼 수 있다(기록 기능만 로그인 필요) — **미정, 확인 필요**.
- Supabase 쪽 설정(사용자가 대시보드에서 직접): 이메일 인증을 켤지 끌지(수업용이면 끄는 편이 시연에 편함), 기본 메일 발송은 시간당 횟수 제한이 있음.
- 비밀번호 입력, 계정 생성은 Claude가 대신하지 않는다. 화면과 연결 코드만 만든다.

## 사진
- 한국관광공사 TourAPI(공식) → 없으면 위키미디어 커먼즈(출처 표기). 사용자 사진 업로드는 나중(리뷰 단계).

## 공공데이터 API
| 기능 | API |
|---|---|
| 관광지 소개·좌표 | 제주 관내 관광지 데이터 (odcloud) |
| 관광지 사진 | 한국관광공사 TourAPI(KorService2) |
| 웰니스 인증 표시 | 한국관광공사 웰니스관광정보 |
| 올레길 | 제주 올레코스 현황 (odcloud) |
| 날씨·공기·일출일몰 | Open-Meteo |
| 맛집·카페 | 카카오 로컬 |
| 에이전트 | Anthropic API |
| 저장·계정 | Supabase |

관광지 이미지 데이터셋(ns 15111745)은 이미지 주소가 사라져 쓰지 않는다.
